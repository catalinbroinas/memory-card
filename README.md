# Memory Card - React Game

A React memory card game where you test your memory by selecting each card only once, built as part of The Odin Project.

## About

Memory Card is a browser-based memory game where the goal is to select each card only once. The game offers three difficulty levels with different round counts.

## Features

* Choose between three difficulty levels: Easy, Medium, and Hard
* Track your score and current round during gameplay
* View your final score and best score
* Save best scores using local storage
* Reset progress, restart the game, or play again

## Technologies

* JavaScript
* React
* Font Awesome
* Vite
